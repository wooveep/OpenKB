# Bound incremental corpus synthesis without truncation

After a new document's candidates validate, OpenKB makes the document available immediately and debounces automatic synthesis of only affected identities while the prior generated generation remains current. Deterministic admission and clustering run before model work, and token-bounded structured batches synthesize several compatible small identities while oversized Procedures run alone; per-item validation isolates retries and prevents cross-item leakage. Each run has visible configurable call and token ceilings. Reaching a ceiling pauses a resumable candidate generation for user continuation instead of dropping low-ranked topics, publishing a partial generation, or blocking document availability; reanalysis of existing documents remains an explicit action.
