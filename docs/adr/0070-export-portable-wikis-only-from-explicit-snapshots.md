# Export portable wikis only from explicit snapshots

Portable Wiki Export is one additional `portable_wiki` mode in the existing transactional export workflow, not a second exporter or a pair of independently configurable layout and resource-policy axes. It materializes an explicitly requested Navigation Snapshot using the same staging, validation, and atomic-publication machinery as current exports. Its semantic layout mirrors the Knowledge Navigation View: `index.md`, `summaries/`, published `concepts/`, `entities/`, and `procedures/`, current `generated/` knowledge, one anchor-preserving Markdown Portable Source View per Available Document Version under `sources/`, referenced images, and a versioned manifest containing snapshot identities, routes, aliases, resources, and checksums. It excludes Raw Assets, drafts, review work, historical generations, prompts, model reasoning, and logs; the existing self-contained bundle remains the mode for exporting referenced originals.

Before starting, the Workbench shows the document count and estimated size. Every link and checksum must validate before a new immutable directory is atomically published. Runtime retrieval never reads the export and imports or generation changes do not keep it synchronized in the background. This accepts that an exported bundle is a point-in-time artifact in exchange for eliminating a second live filesystem representation and its consistency machinery.
