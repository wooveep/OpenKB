# Defer unresolved clusters without blocking safe knowledge

An identity or claim cluster that still requires review does not block an otherwise valid Generated Knowledge Generation. OpenKB carries forward the prior generated item for an existing affected identity; for a new identity it withholds the generated page while keeping its Evidence available to direct retrieval. Safe clusters may therefore activate together in one complete atomic generation without publishing duplicate provisional pages, silently discarding evidence, or allowing one ambiguity to stall the corpus.
